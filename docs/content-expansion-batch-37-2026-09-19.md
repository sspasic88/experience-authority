## Media

Every new guide has a real, locally served and clickable photograph with the standard lower-right `Image: author / source ↗` credit. The media ledger identifies what each image actually depicts, what it does not prove and whether reuse rights were independently documented. No AI-generated image is used.

Konigil's existing guide now uses a stronger current official-source frame from the named Meros paper mill. The prior licensed photograph was accurate, but the replacement reads more clearly at card scale. The credit and rights record were updated with the image.

## Discovery and return

The ten guides join deliberate homepage rotations, the Compass opening, visitor-intent filters and relevant editorial pathways. Ten new authored daily discoveries extend the finite return queue through 15 December 2026. The releases remain dated editorial objects rather than a random endless feed.

## Boundaries

- Public sources support the guide scope, not EA attendance or endorsement.
- Official-source attribution does not equal a reuse licence.
- A museum is not a performance, observation is not a workshop and public visibility is not a request for local people to host a visitor.
- Exact dates, capacity, weather, inventory, performer and host details still require direct confirmation.
- No outreach, booking, payment, partnership request or consent-dependent action was performed.
