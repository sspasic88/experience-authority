# Public typography

Experience Authority uses two self-hosted variable families under the SIL Open Font License 1.1:

- Source Sans 3 for navigation, controls and reading copy. `OFL.txt` is the governing licence.
- Newsreader for editorial display typography. `Newsreader-OFL.txt` is the governing licence.

No supplied Aeonik Pro assets are retained in this public project.

Sources:

- https://github.com/google/fonts/tree/main/ofl/sourcesans3
- https://github.com/google/fonts/tree/main/ofl/newsreader
- https://github.com/productiontype/Newsreader
